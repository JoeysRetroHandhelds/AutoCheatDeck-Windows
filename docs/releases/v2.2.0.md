## Back to basics

AutoCheatDeck goes back to what it does reliably: **finding, downloading, updating and launching FLiNG trainers**. Once a trainer is running, use its own window or its hotkeys.

**The Game Bar widget and the cheat overlay are gone.** FLiNG trainers only react to real clicks and keypresses, so switching cheats from outside the trainer meant briefly showing the trainer and clicking it for you. That couldn't be made reliable (the trainer flashing up, focus jumping, nothing working over exclusive-fullscreen games), so it was removed rather than left half-working.

## If you used the widget
On the first start after updating, AutoCheatDeck removes the old widget. It then asks once for administrator approval to also remove the widget's certificate and network exemption from Windows. Say no and it asks again next time.

## Also
- Launching a trainer shows Windows' usual administrator prompt again (FLiNG trainers run as administrator).
- Send logs no longer includes cheat lists.
