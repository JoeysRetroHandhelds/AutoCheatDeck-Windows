## What's new

**Install the Game Bar widget with one click.** Press **Install Game Bar widget** at the bottom of AutoCheatDeck's window and approve the one administrator prompt (Windows needs to trust the widget's signing certificate; that's asked only once). Then open Game Bar (Win+G, or the Xbox button) and choose **Widgets > AutoCheatDeck**. No more downloading separate files or importing certificates by hand.

When a later AutoCheatDeck update brings a newer widget, the button says **Update Game Bar widget**.

## Notes
- The widget now ships inside the AutoCheatDeck download, which makes it about 16 MB bigger.
- The separate widget files are still attached to the release for anyone who prefers installing by hand (see the README).
