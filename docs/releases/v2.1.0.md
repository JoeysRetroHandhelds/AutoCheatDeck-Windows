## What's new

**Cheats over the game, with a controller.** The new **AutoCheatDeck widget** for Xbox Game Bar starts your trainer and opens a **cheat overlay** over the game. Switch cheats with A, change multipliers and speeds with Left / Right, and type amounts like money with Y. The trainer's own window stays out of the way. There are touch buttons too, and over exclusive fullscreen games (where the controller can't reach the overlay) touch is used instead. Install the widget from `AutoCheatDeckWidget.msixbundle` below; see the README for the one-time certificate step.

**Better trainer search.** Store names with ™, ®, "Deluxe Edition", "GOTY" and so on now find their trainer.

**Know when something changed:**
- **Game updated:** when a game updates after its trainer was installed, AutoCheatDeck says so (trainers are made for specific game versions).
- **Missing trainer:** if Windows Security removes or blocks a trainer, AutoCheatDeck says what happened, opens Protection history for you, and offers to download it again.

**Send logs.** The new **Send logs** button saves everything needed to diagnose a problem in one zip on your Desktop (with your Windows user name blanked out) and opens a pre-filled GitHub issue.

## Also
- Updates are now signed: AutoCheatDeck only installs an update that carries the project's signature.
- Trainers set to Chinese are read in English.
- The window fills small handheld screens.
- A warning not to use trainers in online games with anti-cheat (it can get an account banned).
- Many reliability fixes: damaged settings no longer crash the app, a bad Steam file no longer hides your games, trainers come back when AutoCheatDeck quits, and more.

## Notes
- The cheat overlay and widget need one administrator approval per session (FLiNG trainers run as administrator).
- Use trainers you trust, in single-player games only.
