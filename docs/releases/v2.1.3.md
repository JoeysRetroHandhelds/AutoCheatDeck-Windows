## Fixes

**Cheats switched from the overlay now work in the game.** Before, the overlay showed a cheat as ON but the trainer never actually turned it on. AutoCheatDeck now clicks the trainer's button for real: the trainer may flash on screen for a moment while it does, then it's hidden again and the overlay keeps control.

**Show cheats opens right away.** An error while AutoCheatDeck's window was hidden could open a message you couldn't see, and everything (including Show cheats) waited until it closed. Errors now show in the overlay and the log instead. Pressing Show cheats again while it's open just brings it to the front.

**Clearer logs.** When the admin helper fails, the log now says which step failed.
