## What's new

**Start the trainer with a Steam game.** For a Steam game with a trainer, tick **Start the trainer when I play this game in Steam**. Pressing Play in Steam (desktop, Big Picture or Xbox full screen mode) then starts the game and, a few seconds later, its trainer, without opening AutoCheatDeck first.

- It uses the game's Steam launch options. Steam only saves those while it's closed, so ticking or unticking the box closes Steam and opens it again.
- Launch options you already had are kept, and come back unchanged when you untick it. Steam's settings file is backed up first.
- Prefer to set it up yourself? **Copy the Steam launch option** and paste it into the game's Properties > Launch Options.

## Notes
- Trainers run as administrator, so Windows asks for approval each time the game starts with its trainer.
- If you move the AutoCheatDeck folder, untick and tick the box again so Steam points at the new place.
