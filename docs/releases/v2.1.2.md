## Fixes

**The Game Bar widget can reach AutoCheatDeck.** The widget installed by 2.1.1 got stuck on "Starting AutoCheatDeck...": Windows doesn't let Game Bar widgets connect to other programs on the same PC unless they're given an exemption, and 2.1.1 didn't set it up. If you installed the widget with 2.1.1, press **Finish Game Bar widget setup** at the bottom of AutoCheatDeck and approve the administrator prompt once. New installs get it automatically.

**You can see the widget install happening.** The button now says "Installing the widget..." while it works (it can take a little while), with a note to approve the administrator prompt.
